# manager-training CLAUDE.md

## 目的

このフォルダは、マネージャー研修資料を外部共有用のHTML/CSSページとして公開するための場所。

## 基本ルール

1. 公開URLは `https://shimada-runbird.github.io/ranbird/manager-training/` を前提にする。
2. 編集対象は原則 `index.html` と `styles.css` に限定する。
3. 外部共有前提のため、個人名、未公開の評価情報、機密性の高い社内事情は入れない。
4. デザインは白ベース、ネイビー、ブルー、グリーン、オレンジを基本にし、研修資料として読みやすくする。
5. 内容を更新したら、GitHub Pagesに反映されるように `ranbird` リポジトリへpushする。

## このページのルール

- 元資料は `04_経営戦略/マネージャー研修資料_強い幹部層を作る.md`。
- 図解では、研修の目的、100億への成長曲線、マネージャーの役割、評価基準、行動チェックリストを中心に見せる。
- 研修で使う時に、冒頭で結論が伝わり、中盤で役割が整理され、最後に明日からの行動に落ちる構成にする。
