Compare

ダメ管理職 vs 強い管理職

見た瞬間、自分がどちらか分かるようにする。

ダメ管理職
  • 自分で売る（プレイヤー残留）
  • 感情で怒る・詰めるだけ
  • 部下を放置
  • 数字を見ない
  • 属人化・お気に入り
  • 指示が曖昧
  • 空気を悪くするのに放置
強い管理職
  • 部下を勝たせる
  • 再現性を作る（型・SOP）
  • 数字で見る・週次で直す
  • 教育する（見せる→FB）
  • 仕組み化・AI活用
  • 組織文化を守る
  • 採用と定着まで見る

Action Loop

11 / 14

NG

NGマネジメント — 営業会社あるある

感情マネジメント

怒鳴る・冷やす・無視。数字が落ちる原因を人のせいにする。

詰め文化だけ

原因分析と改善がない。同じミスが繰り返される。

放置

新人を1人で戦場に出す。ロープレゼロで戦力化を期待する。

人によって態度変更

お気に入りとそうでない人で基準が違う。組織の信頼が壊れる。

指示が曖昧

「頑張って」「なんとかして」だけ。何をいつまでにやるか不明。

エース放置

数字は出るが空気を壊す人を放置。チーム全体の生産性が下がる。

Case Work

ケースワーク — 考えて持ち帰る

正解は1つではない。管理職としての打ち手を言語化する。

CASE 01

数字が落ちた営業

アポは取れているが受注率が2ヶ月低下。本人は「リストが悪い」と言う。

→ 何を見て、誰と、何を直す？ 1週間の行動計画は？

CASE 02

空気を悪くするエース

個人の数字はトップ。後輩への口は悪く、会議で発言しない人が増えた。

→ 放置する？ 役割変更？ 1on1で何を伝える？

CASE 03

新人が辞めそう

入社2ヶ月。ロープレが少なく、一人でテレアポしている。表情が曇っている。

→ 明日から変える3アクションは？
